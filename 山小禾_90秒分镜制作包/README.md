# 山小禾的余村山野巡行

“两山理念 · 乡村文旅的设计实践”90秒概念短片制作包。题材场景为浙江安吉余村，采用软质三维手作风格。

**当前状态：18镜头分镜与提示词已完成，实际新生成首帧0张，视频0条。** OpenAI API路径已授权，等待本机配置密钥；尚未上传GitHub。

- `山小禾_Obsidian交接笔记.md`：项目状态、素材导航、执行清单与接手提示；在Obsidian中打开整个制作包使用。
- `分镜预览.html`：下载后在浏览器中打开的离线分镜预览。
- `完整分镜与提示词.md`：导演执行稿、冻结首帧和视频提示词。
- `剪辑镜头表.csv` 与 `分镜数据.json`：18镜、90秒时间轴及结构化数据。
- `01_角色参考`：用户原始图片及裁切，均非新生成分镜。
- `02_逐镜提示词`：每镜的图片与视频制作说明。
- `03_待生成首帧`：实际出图后按SH01.png至SH18.png保存。
- `04_技能来源`：从GitHub安装的导演辅助技能、固定提交和MIT许可。
